# DestinyStory v2.5.0 — Huit archétypes, quatre duels

- **Huit archétypes, trois vêtements chacun.** Le Débrouillard, le Cynique, l'Opportuniste et le Solitaire disparaissent ; le Gardien de l'ordre devient le **Tyran** (« Impose sa loi, rationne, punit qui désobéit »). Les 24 animaux restent, redistribués : le Renard rejoint le Leader, le Cerf le Protecteur, la Souris l'Aidant, le Chat l'Alarmiste, le Singe le Dénégateur, le Hibou le Prophète, la Hyène le Tyran, le Vautour le Paranoïaque, avec une posture, une réplique et un exemple de vouloir à leur mesure.
- **On distribue par duels** : l'Alarmiste contre le Dénégateur (ce qu'est le danger), le Leader contre le Tyran (qui commande), l'Aidant contre le Paranoïaque (les autres), le Protecteur contre le Prophète (la victime). À la préparation, chaque personnage voit son adversaire, et les duels s'affichent sous la liste. Le tirage tire des duels entiers ; dès quatre joueurs, les trois couleurs sont sur scène.
- **En mode kids**, le Vautour dit « Mon précieux… » ; le Renard garde sa nouvelle réplique (« J'adore quand un plan se déroule sans accroc »).
- **Les cartes d'archétypes à imprimer sont refaites** : huit cartes paysage par page, l'archétype, son icône, son duel et sa montée à gauche, ses trois vêtements (photo, port, statut, réplique, exemple de vouloir) à droite ; au verso, le dé Destiny. Les cartes d'animaux et de dangers prennent le même style.
- Les préparations, troupes et séries déjà enregistrées passent toutes seules aux nouveaux archétypes.
